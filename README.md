# Sania Konveksi

Sania Konveksi is a web application for a convection business, allowing customers to browse products, view portfolios, place orders, and providing an admin panel for managing products, portfolios, and orders.

## Features

* **Product Display**: Showcase various convection products with details, pricing, and stock information.
* **Product Categories**: Organize products by different types (e.g., Polo, Kaos, Kemeja).
* **Portfolio Display**: Exhibit previous work and projects.
* **Order Placement**: Allow users to initiate orders (though the full ordering process seems to link to WhatsApp).
* **Admin Dashboard**: A dedicated panel for administrators to manage:
    * Products (add, manage)
    * Portfolios (add, manage)
    * Orders (view)
    * Sewing Tools (view)
* **User Authentication**: Secure login for administrators.
* **Responsive Design**: Adapts to various screen sizes for a better user experience.
* **Search and Filter**: Filter products by type and price range on the order page.
